# osTicket Help Desk Lab (Open Source Ticketing System)

## Overview
This lab demonstrates how a help desk ticketing system is installed, configured, and used to support users.
It simulates real-world IT support workflows including ticket creation, prioritization, escalation, and resolution.

## What I Built
- Installed and configured osTicket (open-source ticketing system)
- Created users, agents, departments, and roles
- Simulated common IT support tickets
- Applied ticket priorities and SLAs
- Documented troubleshooting and resolution steps

## Skills Demonstrated
- Help Desk ticket lifecycle (open → assign → resolve → close)
- User vs agent workflows
- SLA and priority handling
- Documentation and communication
- Basic Linux / web server administration

## Tools Used
- osTicket
- Ubuntu Server / Apache / PHP / MySQL
- Browser-based client access
